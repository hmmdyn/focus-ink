# 아이폰 방해 통제 시스템 (단축어 + 자동화 + 스크린 타임)

아이폰은 **방해를 막고, 못 막은 것은 기록해서 e-ink 로 보내는** 역할만 한다. 집중 자체는 Palma 2 에서 한다.

설정 시간: 약 40분, 한 번만. iOS 17 이상 기준(자동화 "즉시 실행" 필요).

## 0. 준비

1. Palma 2 의 Focus Ink → **설정 → 아이폰 연동** 에서 `연동 켜기` 를 누르고 **토픽**을 확인한다(예: `focusink-ab3k9xq2m7pwze`). 이하 `<토픽>`.
2. 아이폰 **설정 → 손쉬운 사용 → 디스플레이 및 텍스트 크기 → 색상 필터** 에서 필터를 **흑백(Grayscale)** 으로 골라 둔다(켜고 끄기는 단축어가 한다).
3. App Store 에서 **ntfy** 앱 설치 → `+` → 토픽 `<토픽>` 구독(서버 기본값 ntfy.sh). e-ink 에서 세션을 시작·종료하면 아이폰에 알림이 온다.
4. 단축어 앱에서 아래 단축어를 만든다. 모든 단축어가 쓰는 **보내기 블록**:

> **[보내기 블록]**
> 1. `텍스트` — 보낼 한 줄 (예: `방해 Instagram`)
> 2. `URL 내용 가져오기` — URL `https://ntfy.sh/<토픽>`, 방법 **POST**, 요청 본문 **파일**, 파일 = 1번의 `텍스트`

연결 확인: 단축어 하나에 `텍스트: 할일 연결 테스트` + 보내기 블록을 넣어 실행 → Palma 2 에서 Focus Ink 를 열면 오늘 할 일에 "연결 테스트"가 들어와 있어야 합니다.

## 1. 단축어 6개

### ① 잠깐 멈춤 (유혹 앱을 열 때마다)

입력: 앱 이름(자동화가 넘겨줌). 한 번 "그래도 열기" 를 고르면 10분 동안은 다시 묻지 않는다.

1. `파일 가져오기` — 단축어 폴더의 `focusink-grace.txt`, "찾을 수 없으면 오류" **끔**
2. `만약` 파일 **값이 있음** →
   - `입력에서 날짜 가져오기` (파일)
   - `날짜 간 시간 가져오기` — 그 날짜 ~ `현재 날짜`, 단위 **분**
   - `만약` 결과 **< 10** → `단축어 중단`
   - `만약 끝`
3. `만약 끝`
4. `홈 화면으로 이동`
5. `대기` 5초 (숨 한 번)
6. `메뉴에서 선택` — 질문: `단축어 입력`을 정말 열까요? 오늘 가장 중요한 일을 떠올려 보세요.
   - **안 열기** → 텍스트 `충동 [단축어 입력]` + 보내기 블록 → `알림 보기` "잘 참았어요. e-ink 로 돌아가요."
   - **10분 뒤에** → 텍스트 `충동 [단축어 입력]` + 보내기 블록 → `타이머 시작` 10분 → `알림 보기` "10분만 기다려 보세요. 하고 싶은 마음은 대개 금방 지나가요."
   - **그래도 열기** →
     1. `텍스트` = `현재 날짜` → `파일 저장` 단축어 폴더 `focusink-grace.txt`, **덮어쓰기 켬**, "저장 위치 묻기" 끔
     2. 텍스트 `방해 [단축어 입력]` + 보내기 블록
     3. `사전` — 키/값: `Instagram`=`instagram://`, `YouTube`=`youtube://`, `TikTok`=`snssdk1233://`, `X`=`twitter://`, `카카오톡`=`kakaotalk://`
     4. `사전 값 가져오기` 키 = `단축어 입력` → `URL 열기`

### ② 딥워크 시작

1. `메뉴에서 선택` — 90분 / 50분 / 25분 → 각각 `숫자` 90/50/25 → 변수 `분`
2. `입력 요청` — "무엇을?" (텍스트)
3. `날짜 조정` — `현재 날짜` 에 `분` 분 더하기 → 변수 `끝`
4. `집중 모드 설정` — **업무**(또는 직접 만든 "딥워크") 켜기, 끄는 시점 **시간: `끝`**
5. `색상 필터 설정` — 켜기
6. 텍스트 `시작 [분] [입력 요청 결과]` + 보내기 블록 → e-ink 에 세션이 자동으로 시작된다
7. `알림 보기` "휴대폰은 다른 방에 두고 e-ink 로 집중해요."

### ③ 딥워크 끝

1. `집중 모드 설정` — 업무 끄기
2. 텍스트 `종료` + 보내기 블록

### ④ 1분 컬러 (흑백 유지 중 잠깐 색이 필요할 때)

1. `색상 필터 설정` — 끄기
2. `대기` 60초
3. `색상 필터 설정` — 켜기

**설정 → 손쉬운 사용 → 터치 → 뒷면 탭 → 이중 탭** 에 연결.

### ⑤ 빠른 할 일 (떠오른 일을 e-ink 저널로)

1. `입력 요청` — "할 일" (앞에 `-` 를 쓰면 메모)
2. `만약` 입력이 `-` 로 시작 → 텍스트 `메모 [입력]` / 아니면 → 텍스트 `할일 [입력]`
3. 보내기 블록

**뒷면 탭 → 삼중 탭** 또는 동작 버튼에 연결.

### ⑥ 흔들림 기록 (폰을 집어 들었다는 걸 알아챘을 때)

1. `메뉴에서 선택` — SNS / 메시지 / 그냥 폰 / 딴생각
2. 텍스트 `방해 [선택한 항목]` + 보내기 블록
3. `홈 화면으로 이동`

## 2. 개인 자동화 6개 (모두 **즉시 실행**, "실행 시 알림" 끔)

| 트리거 | 동작 | 근거 |
| --- | --- | --- |
| **앱** Instagram **열림** | `단축어 실행` ① 잠깐 멈춤, 입력 = 텍스트 `Instagram` | 3초 멈춤 앱(one sec) 방식 |
| **앱** YouTube **열림** | ① 입력 `YouTube` | 〃 |
| **앱** TikTok / X / 카카오톡 **열림** | 앱마다 하나씩, 입력 = 앱 이름(사전 키와 같게) | 〃 |
| **알람** 기상 알람 **중단됨** | `집중 모드 설정` "아침 보호"(새로 만들기) 켜기, 끄는 시점 = 현재+3시간 · `색상 필터 설정` 켜기 · `알림 보기` "첫 3시간은 폰 없이. e-ink 에서 Top 3 확인" | 기상 후 3시간 폰 금지 |
| **시간** 매일 22:30 (휴대폰 내려놓는 시각) | `집중 모드 설정` 수면 켜기 · `색상 필터 설정` 켜기 · `알림 보기` "휴대폰은 침대 밖에서 충전해요" | 잠들기 전 화면 끄기 |
| **충전기** 연결됨 | `만약` 현재 시각이 22:00 이후 → 텍스트 `메모 휴대폰 내려놓음` + 보내기 블록 | 내려놓은 시각 기록 |

> 앱 이름은 사전 키와 정확히 같아야 "그래도 열기" 가 동작한다.

## 3. 집중 모드 (설정 → 집중 모드)

- **업무/딥워크**: 알림 허용 = 즐겨찾기 연락처만. 홈 화면 = 전화·메시지·지도만 있는 페이지 1개. 잠금 화면 = 위젯 없음.
- **아침 보호**: 업무와 같은 설정. 기상 자동화가 3시간 켠다.
- **수면**: 선셋 자동화가 켠다.

## 4. 스크린 타임 (설정 → 스크린 타임)

1. **다운타임**: 22:30 ~ 07:30, "다운타임 중 차단" 켬.
2. **앱 시간 제한**: 소셜 네트워킹·엔터테인먼트 합계 **30분/일**, "제한 시간 끝나면 차단" 켬.
3. **항상 허용**: 전화, 메시지, 지도, ntfy.
4. **스크린 타임 암호**: 본인이 외우지 않는 숫자로 바꾸고 종이에 적어 서랍에(마찰을 만드는 것이 목적).

## 5. 추가 추천 (강병준 영상 방식)

- 문제 앱 삭제 → Safari 로만 접속. Safari 확장 **Untrap**(유튜브 추천·댓글·쇼츠 숨김), **Social Focus**(인스타 피드·릴스 숨김).
- 알림: 사람에게서 오는 것(전화·메시지) 외 전부 끄기.
- 홈 화면 1페이지만, 아이콘 대신 위젯/검색으로 실행.
