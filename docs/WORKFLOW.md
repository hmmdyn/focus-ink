# 하루·주간 워크플로

도구는 시스템을 대신하지 않는다. 아래 흐름을 **같은 시간, 같은 장소**에서 반복하는 것이 목적이다. Focus Ink 의 "오늘" 화면 맨 위 검은 상자가 매 순간 이 흐름의 다음 단계를 하나만 보여 준다.

## 아침 (기상 ~ 첫 블록, 15분)

1. 알람을 끄면 아이폰은 흑백 + 아침 보호 3시간. **폰은 주차장에 그대로.**
2. Palma 2 를 들고 **오늘** 화면.
3. **옮겨 적기**: 지난 미완료를 하나씩 — 다시 적어 옮기기 / 이미 했음 / 지우기. 2번 이상 옮긴 일은 더 작게 쪼갠다.
4. **Top 3** 확인(어젯밤 리뷰에서 정한 것). 없으면 지금 정한다.
5. **습관**: 작은 버전이라도 체크.

## 오전 딥워크 (3시간 = 90분 × 2)

1. **집중** 탭: 블록 길이, 무엇을, "끝나면 무엇이 되어 있어야 하나"(의도) 입력. 준비 체크(폰 주차, 탭 정리, 물).
2. 시작 → **닻 15분**: 종료 버튼이 없다. 다른 창을 열지 않는다.
3. 충동이 오면 **충동이 왔다** → 10분 버티기 → 지나갔다/졌다.
4. 흔들렸으면 **흔들림 기록**(무엇이 흔들었는지 한 번 누름).
5. 끝나면 **회고**(집중도, 한 줄) → **휴식 5분**(물·스트레칭·먼 곳 보기, 폰 금지) → 두 번째 블록.

메이커 데이(기본: 월·화·목·금): 오전 전체를 딥워크로. 매니저 데이(기본: 수·금 설정 변경 가능): 통화·회의를 오후 늦게부터 거꾸로 채운다.

## 오후

- 두 번째 업무(메일·회의·잡무)는 오후에. 떠오르는 일은 e-ink 빠른 기록 또는 아이폰 ⑤ 빠른 할 일.
- 에너지가 남으면 50분 블록 하나 더.

## 저녁 리뷰 (알림 시각, 3분)

1. 오늘 결과(딥워크 분·블록·방해) 확인.
2. 못 끝낸 일 → 내려놓기(내일 아침 옮겨 적기에서 다시 결정).
3. 아직 안 한 습관 → 지금 2분만.
4. 한 줄 회고.
5. **내일 Top 3** 입력.

## 디지털 선셋 (알림 시각)

폰은 침대 밖에서 충전(주차장). 화면 대신 종이책·일기. 매일 같은 시각에 잔다.

## 주간 (일요일 저녁 10분)

1. **기록** 탭 → 7일 딥워크 막대, 완주율, 평균 집중도.
2. **방해 원인 1위**를 "이번 주 제거 대상"으로 정하고 구체적 방법 한 줄(예: "카톡 알림 끄고 점심에만 확인"). 매주 **하나만** 없앤다.
3. 습관 격자에서 "두 번 연속 놓침" 이 있었다면 작은 버전을 더 작게.
4. 습관이 자동이 됐다면(30일, 완료율 80% 이상) 다음 습관 하나를 추가.

## 지키는 규칙 5개

1. 한 블록에 한 가지.
2. 닻 15분은 무조건.
3. 두 번 연속 빠지지 않기.
4. 미룬 일은 손으로 다시 옮겨 적기.
5. 폰은 주차장에.
