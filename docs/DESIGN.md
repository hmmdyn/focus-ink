# Focus Ink 설계

Boox Palma 2(6.13", 824×1648, Android 13, e-ink)를 **집중 전용 기기**로 쓰고, 아이폰은 단축어·스크린 타임으로 **방해를 차단·기록**하는 2-기기 시스템이다. 근거는 Focus 프로젝트의 영상 13편 정리 문서.

## 1. 원칙 → 기능 매핑

| 원칙 (출처) | 앱 기능 |
| --- | --- |
| 덜어내기, 무자극 (Mikey, 강병준, 도래기책방) | e-ink 흑백 UI, 애니메이션·색·피드 없음, 알림은 리뷰·선셋 2개뿐 |
| 첫 15분 닻 내리기 (도래기책방) | 세션 시작 후 15분은 "닻" 단계: 화면에 종료 버튼 숨김 |
| 90분 블록 + 5분 휴식 (SooWei, Dan) | 기본 90분, 50/25분 선택, 완료 후 휴식 화면 |
| 의도 → 집중 → 회고 (Session 앱 흐름) | 시작 전 "이번 블록에서 끝낼 것" 입력, 끝나면 결과·집중도 기록 |
| 충동에 10분 시간차 (도래기책방) | 집중 화면 "충동이 왔다" → 10분 버티기 카운트다운 → 지나갔는지 기록 |
| 방해 요소 탐정 기록, 매주 하나 제거 | 방해 기록(수동 + 아이폰 자동), 주간 상위 원인 → "이번 주 제거할 것" 지정 |
| 불렛저널, 미룬 일 다시 옮겨 적기 (펜조이) | 날짜별 로그(• 할 일, – 메모, * 중요), 지난 미완료는 하나씩 옮기기/지우기 결정, 옮긴 횟수 표시 |
| 내일 Top 3, 미완료 정리, 고정 취침 (RelentX) | 저녁 리뷰: 오늘 결과 → 미완료 처리 → 내일 Top 3 입력 |
| 한 가지, 아주 작게, 사슬, 두 번 연속 금지 (Knowspire) | 습관: "작은 버전"과 "~한 후에" 앵커, 21일 X 격자, 어제 놓치면 "오늘은 꼭" 경고 |
| 최소 기준선 (Dan) | 습관에 "기준선" 표시: 나쁜 날에도 지킬 것 |
| 회의·통화는 몰아서 (SooWei) | 오늘 화면에서 메이커/매니저 데이 표시 (설정 요일) |

## 2. 화면 구조

하단 탭 5개(텍스트만): **오늘 · 집중 · 저널 · 습관 · 기록**. 설정은 오늘 화면 우상단.

- **오늘**: 날짜, 데이 유형, 지금 할 일 한 줄(상태 기반 안내), Top 3, 옮겨 적기 대기 수, 습관 체크, 오늘 딥워크 분/블록, 이번 주 제거 대상. 저녁 리뷰 시각 이후엔 리뷰 카드가 맨 위.
- **집중**: 대기(블록 길이·과제 선택·의도) → 진행(닻/딥/초과 단계, 분 단위 갱신) → 회고 → 휴식.
- **저널**: 날짜 이동, 빠른 입력(접두어 `-` 메모, `*` 중요), 옮겨 적기 모드.
- **습관**: 목록, 21일 격자, 추가/보관.
- **기록**: 최근 7일 딥워크 막대, 완료율, 방해 원인 순위, 방해 로그, 주간 제거 대상 지정.

## 3. e-ink UI 규칙 (Palma 2)

1. 흑(#000)·백(#FFF)만. 회색은 1px 테두리용 하나만.
2. 애니메이션·리플 0. 누르는 동안 **반전(흑 배경·백 글자)** 으로 피드백.
3. 타이머는 **분 단위**로만 갱신(초 단위 갱신은 잔상 유발).
4. 스크롤 대신 **페이지 넘김**(이전/다음) 목록, 한 페이지 8줄.
5. 터치 영역 최소 52dp, 본문 18sp, 숫자 강조 72sp 이상.
6. 세션 시작·종료 시 한 번 "전체 새로고침"(흑→백 플래시)으로 잔상 제거.
7. 세션 중 화면 꺼짐 방지(e-ink는 정지 화면 전력이 거의 0).
