# Focus Ink 설계

Boox Palma 2(6.13", 824×1648, Android 13, e-ink)를 **집중 전용 기기**로 쓰고, 아이폰은 단축어·스크린 타임으로 **방해를 차단·기록**하는 2-기기 시스템이다. 근거는 Focus 프로젝트의 영상 13편 정리 문서.

## 1. 원칙 → 기능 매핑

| 원칙 (출처) | 앱 기능 |
| --- | --- |
| 덜어내기, 무자극 (Mikey, 강병준, 도래기책방) | 흑백 e-ink 화면, 애니메이션·색·피드 없음, 알림은 하루 두 번뿐 |
| 처음 15분은 자리 지키기 (도래기책방) | 집중을 시작하고 15분 동안은 멈추려면 두 번 눌러야 함 |
| 90분 집중 + 5분 휴식 (SooWei, Dan) | 기본 90분, 50·25분 선택, 끝나면 쉬는 시간 화면 |
| 의도 → 집중 → 돌아보기 (Session 앱 흐름) | 시작 전에 끝났을 때의 모습을 적고, 끝나면 집중도와 한 줄 메모 |
| 하고 싶은 마음에 10분 시간차 (도래기책방) | "딴짓하고 싶어요" → 10분 기다리기 → 괜찮아졌는지 기록 |
| 딴짓 기록, 매주 하나 줄이기 | 딴짓 기록(직접 + 아이폰 자동), 가장 많은 원인을 이번 주 목표로 |
| 불렛저널, 미룬 일 다시 적기 (펜조이) | 날짜를 넘기는 수첩(• 할 일, – 메모, 번호 = 중요), 지난 할 일은 하나씩 다시 적어 옮기거나 지우기, 옮긴 횟수 표시 |
| 내일 할 일 세 가지, 고정 취침 (RelentX) | 하루 마무리: 오늘 한 일 → 남은 일 → 습관 → 한 줄 회고 → 내일 가장 중요한 일 |
| 하나만, 아주 작게, 두 번 연속 빠지지 않기 (Knowspire) | 습관마다 가장 작은 버전과 하는 때, 4주 격자, 어제 빠졌으면 오늘 알림 |
| 회의·통화는 몰아서 (SooWei) | 설정한 요일에는 오늘 쪽에 "회의를 몰아 두는 날" 안내 |

## 2. 화면 구조 (종이 수첩형)

아래 탭은 **오늘 · 집중 · 기록** 세 개입니다.

- **오늘**: 수첩의 한 쪽입니다. 머리말의 날짜 양옆 ‹ › 로 지난 쪽과 다음 쪽을 넘깁니다. 맨 위에 지금 해야 할 일을 한 문장과 버튼 하나로 보여 주고, 그 아래에 그날의 할 일(중요한 일은 번호, 나머지는 •, 끝낸 일은 ×, 메모는 –)과 습관 체크, 꼬리말 요약이 이어집니다. 설정은 머리말 오른쪽에 있습니다.
- **집중**: 고르기(할 일, 시간, 끝났을 때의 모습) → 진행(처음 15분, 집중, 시간 초과) → 돌아보기 → 쉬는 시간.
- **기록**: 지난 7일 막대그래프, 습관별 4주 격자, 딴짓 원인 순위와 이번 주 목표, 최근 딴짓 기록.
- 겹쳐 뜨는 화면: 지난 할 일 정리, 가장 중요한 일 고르기, 하루 마무리, 설정.

## 3. e-ink 화면 규칙 (Palma 2)

Kindle, reMarkable, Light Phone 처럼 종이에 가까운 화면을 기준으로 삼았습니다.

1. 흑백과 회색 한 단계만 씁니다. 그림자, 색, 애니메이션은 쓰지 않습니다.
2. 구역은 1dp 실선으로 나누고, 테두리 상자는 꼭 필요한 곳에만 둡니다.
3. 날짜, 제목, 큰 숫자는 명조로, 목록과 버튼은 고딕으로 씁니다.
4. 버튼은 글자가 중심이 되게 만들고, 한 화면에 검은 버튼은 하나만 둡니다.
5. 누르는 동안 흑백을 뒤집어 눌렸다는 것을 보여 줍니다.
6. 타이머는 1분마다만 바뀝니다. 초 단위로 바꾸면 잔상이 남습니다.
7. 긴 목록은 스크롤 대신 쪽을 넘깁니다. 터치 영역은 최소 46dp입니다.
8. 집중을 시작하고 끝낼 때 화면을 한 번 검게 했다가 지워서 잔상을 없앱니다.

## 3-1. 문구 규칙

[fluent-korean](https://github.com/snflkd/fluent-korean) 지침과 토스 같은 국내 서비스의 해요체를 따릅니다.

1. 안내는 조사와 어미를 갖춘 완결된 문장으로 씁니다. "남은 일 3" 대신 "지난 할 일 3개가 남아 있어요"라고 씁니다.
2. 버튼은 동작을 나타내는 말로 씁니다(시작하기, 저장하기, 정리하기).
3. 비유어 대신 일상어를 씁니다. 닻 → 처음 15분, 주차장 → 다른 방, 디지털 선셋 → 휴대폰 내려놓기, 충동 서핑 → 딴짓하고 싶을 때 기다리기.
4. 화면마다 부제를 붙이지 않습니다. 설명은 필요한 순간에만 한 줄로 보여 줍니다.
5. 엠대시(—)는 쓰지 않습니다.
6. 받침에 따라 조사를 바꿉니다(메시지예요, 휴대폰이에요).
