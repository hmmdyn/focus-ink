# Focus Ink 설계

Boox Palma 2(6.13", 824×1648, Android 13, e-ink)를 **집중 전용 기기**로 쓰고, 아이폰은 단축어·스크린 타임으로 **방해를 차단·기록**하는 2-기기 시스템이다. 근거는 Focus 프로젝트의 영상 13편 정리 문서와, 참고 앱 23개·연구를 정리한 [RESEARCH.md](RESEARCH.md).

## 1. 원칙 → 기능 매핑

| 원칙 (출처) | 앱 기능 |
| --- | --- |
| 덜어내기, 무자극 (Mikey, 강병준, 도래기책방) | 흑백 e-ink 화면, 애니메이션·색·피드 없음, 알림은 하루 두 번뿐 |
| 처음 15분은 자리 지키기 (도래기책방) | 집중을 시작하고 15분 동안은 멈추려면 두 번 눌러야 함 |
| 90분 집중 (SooWei, Dan). 90분 주기 자체는 근거가 약함 | 기본 90분, 50·25분 선택 |
| 짧은 휴식은 길수록 회복에 도움 (Albulescu 2022) | 쉬는 시간 = 집중 시간의 1/6, 최소 설정값(90 → 15분, 50 → 8분, 25 → 5분) |
| 의도 → 집중 → 돌아보기 (Session 앱 흐름) | 시작 전에 끝났을 때의 모습을 적고, 끝나면 집중도와 한 줄 메모 |
| if-then 계획 (Gollwitzer & Sheeran 2006) | 시작할 때 "딴짓하고 싶어지면 → 이렇게 한다"를 고르고, 딴짓하고 싶을 때 그 문장을 다시 보여 줌 |
| 다시 시작할 계획 적기 (Leroy & Glomb 2018, Session 앱) | 끝낼 때 "다음에 이어서 할 일"을 적고, 같은 일로 집중을 준비하면 "지난번에 여기서 멈췄어요"로 보여 줌 |
| 하고 싶은 마음에 10분 시간차 (도래기책방, one sec 연구) | "딴짓하고 싶어요" → 10분 기다리기 → 괜찮아졌는지 기록 |
| 딴짓 기록, 매주 하나 줄이기 | 딴짓 기록(직접 + 아이폰 자동), 가장 많은 원인을 이번 주 목표로 |
| 불렛저널, 미룬 일 다시 적기 (펜조이) | 날짜를 넘기는 수첩(• 할 일, – 메모, 번호 = 중요), 지난 할 일은 하나씩 다시 적어 옮기거나 지우기, 옮긴 횟수 표시 |
| 내일 할 일 세 가지, 고정 취침 (RelentX) | 하루 마무리: 오늘 한 일 → 남은 일 → 습관 → 한 줄 회고 → 내일 가장 중요한 일 → 내일 첫 집중 시각 |
| "언제 할지"까지 정한 계획 (실행 의도) | 내일 첫 집중 시각을 정하면 다음 날 오늘 쪽 맨 위에 "09:00에 첫 집중을 시작해요" |
| 계획 오류 (Buehler 1994) | 가장 중요한 일을 고를 때 지난 7일 하루 평균 집중 시간을 함께 보여 줌 |
| 하나만, 아주 작게, 두 번 연속 빠지지 않기 (Knowspire, Atoms) | 습관마다 가장 작은 버전과 하는 때, 4주 격자, 어제 빠졌으면 "오늘은 책 펴기라도 해요" |
| 비상 예비분 (Sharif & Shu), 끊긴 연속의 의욕 저하 (Silverman & Barasch 2023) | 습관마다 주 1회 "쉬어 가기". 쉬는 날은 놓친 날로 세지 않고 연속 기록도 이어짐 |
| 습관 자리 잡기 중앙값 66일 (Lally 2010), Loop 의 습관 강도 | "익숙해진 정도" 점수: 매일 하면 66일에 약 97%, 하루 빠지면 약 5%p 내려감 |
| 돌아온 것 알아봐 주기 (Milkman 2021), 새 출발 효과 (Dai 2014) | 놓친 뒤 다시 하면 "다시 돌아왔어요", 이틀 넘게 쉬었으면 월요일·1일에 "새로 시작하기 좋은 날이에요" |
| 회의·통화는 몰아서 (SooWei) | 설정한 요일에는 오늘 쪽에 "회의를 몰아 두는 날" 안내 |

## 2. 화면 구조 (종이 수첩형)

아래 탭은 **오늘 · 집중 · 기록** 세 개입니다.

- **오늘**: 수첩의 한 쪽입니다. 머리말의 날짜 양옆 ‹ › 로 지난 쪽과 다음 쪽을 넘깁니다. 맨 위에 지금 해야 할 일을 한 문장과 버튼 하나로 보여 주고, 그 아래에 그날의 할 일(중요한 일은 번호, 나머지는 •, 끝낸 일은 ×, 메모는 –)과 습관 체크, 꼬리말 요약이 이어집니다. 설정은 머리말 오른쪽에 있습니다.
- **집중**: 고르기(할 일, 시간, 끝났을 때의 모습) → 진행(처음 15분, 집중, 시간 초과) → 돌아보기 → 쉬는 시간.
- **기록**: 지난 7일 막대그래프, 습관별 4주 격자, 딴짓 원인 순위와 이번 주 목표, 최근 딴짓 기록.
- 겹쳐 뜨는 화면: 지난 할 일 정리, 가장 중요한 일 고르기, 하루 마무리, 설정.

## 3. e-ink 화면 규칙 (Palma 2)

Kindle, reMarkable, Light Phone 처럼 종이에 가까운 화면을 기준으로 삼았습니다.

1. 흑백과 회색 한 단계만 씁니다. 그림자, 색, 애니메이션은 쓰지 않습니다.
2. 구역은 1dp 실선으로 나누고, 테두리 상자는 꼭 필요한 곳에만 둡니다.
3. 날짜, 제목, 큰 숫자는 명조로, 목록과 버튼은 고딕으로 씁니다.
4. 버튼은 글자가 중심이 되게 만들고, 한 화면에 검은 버튼은 하나만 둡니다.
5. 누르는 동안 흑백을 뒤집어 눌렸다는 것을 보여 줍니다.
6. 타이머는 1분마다만 바뀝니다. 초 단위로 바꾸면 잔상이 남습니다.
7. 긴 목록은 스크롤 대신 쪽을 넘깁니다. 터치 영역은 최소 48dp입니다(Material 기준).
8. 집중을 시작하고 끝낼 때 화면을 한 번 검게 했다가 지워서 잔상을 없앱니다.

## 3-1. 문구 규칙

[fluent-korean](https://github.com/snflkd/fluent-korean) 지침, [앱인토스 UI/UX 가이드](https://developers-apps-in-toss.toss.im/design/consumer-ux-guide.md)의 해요체 규칙을 바탕으로, 습관 앱의 **코치 말투**(옆에서 권하고, 해낸 것을 알아봐 주고, 멈췄을 때 탓하지 않는 말투)를 씁니다. 분석 근거는 [RESEARCH.md](RESEARCH.md#문구-코치-말투).

1. 안내는 조사와 어미를 갖춘 완결된 문장으로 씁니다. "남은 일 3" 대신 "지난 할 일 3개가 남아 있어요"라고 씁니다.
2. 버튼은 동작을 나타내는 말로 씁니다(시작하기, 저장하기, 정리하기).
3. 비유어 대신 일상어를 씁니다. 닻 → 처음 15분, 주차장 → 다른 방, 디지털 선셋 → 휴대폰 내려놓기, 충동 서핑 → 딴짓하고 싶을 때 기다리기.
4. 화면마다 부제를 붙이지 않습니다. 설명은 필요한 순간에만 한 줄로 보여 줍니다.
5. 엠대시(—)는 쓰지 않습니다.
6. 받침에 따라 조사를 바꿉니다(메시지예요, 휴대폰이에요). 조사는 앞말에 붙여 씁니다(09:00처럼, e-ink로).
7. **시작은 권해요.** "정해 주세요"보다 "정해 볼까요?", "적어 주세요"보다 "적어 볼까요?". "~해 주세요"는 꼭 필요한 입력 오류에만 씁니다.
8. **해낸 것은 숫자로 알아봐 줘요.** "끝까지 해냈어요!", "2번 참았어요", "7일째예요!".
9. **멈췄을 때는 탓하지 않고 다음 한 걸음만 말해요.** "어제 못 했어요" 대신 "오늘은 책 펴기라도 해 봐요. 두 번 연속만 빠지지 않으면 돼요."
10. **이유는 한 줄만 덧붙여요.** "처음 15분은 멈출 수 없어요. 그 고비만 넘기면 돼요."
11. **느낌표는 해낸 순간에만 한 번.** 집중을 끝까지 마쳤을 때, 습관으로 돌아왔을 때, 이정표(7·14·21·30·50·66·100일), 딴짓을 참았을 때.
12. **하지 않는 말**: 손실·벌금 강조("연속 기록이 끊겨요!"), 경쟁 자극, "정말 포기할 건가요?" 같은 죄책감 주기, 앱이 "저"로 말하기, 명사형 상태 표시("동기화 실패", "그만둠").
13. 보조 버튼은 "취소" 대신 "닫기"를 씁니다.
