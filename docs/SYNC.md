# 아이폰 ↔ e-ink 연동 프로토콜

서버 없이 [ntfy.sh](https://ntfy.sh)(무료, 계정 불필요 pub/sub)를 우체통으로 쓴다.

- 토픽: 앱 첫 실행 때 만든 `focusink-xxxxxxxxxxxx` (설정 화면에 표시). **토픽 이름이 곧 비밀번호**이니 공유하지 말 것.
- 서버 기본값 `https://ntfy.sh` (자체 호스팅 ntfy로 바꿀 수 있음).
- ntfy.sh는 메시지를 약 12시간 보관한다. e-ink 앱을 12시간 안에 한 번 열면 그 사이 아이폰 기록이 모두 들어온다.

## 아이폰 → e-ink (명령)

단축어의 "URL 내용 가져오기" 동작으로 `POST https://ntfy.sh/<토픽>`, 본문은 **일반 텍스트 한 줄**.

| 본문 | 의미 | 예 |
| --- | --- | --- |
| `방해 <앱/내용>` (`DISTRACT`) | 방해 1건 기록(출처: 아이폰) | `방해 Instagram` |
| `충동 <앱>` (`URGE`) | 열려다 참음(충동 이김) 기록 | `충동 YouTube` |
| `할일 <내용>` (`TASK`) | 오늘 저널에 할 일 추가 | `할일 논문 3장 요약` |
| `메모 <내용>` (`NOTE`) | 오늘 저널에 메모 추가 | `메모 실험 아이디어` |
| `시작 [분] [이름]` (`START`) | 집중 세션 시작(진행 중이면 무시) | `시작 90 SLAM 코드` |
| `종료` (`STOP`) | 진행 중 세션 완료 처리 | `종료` |

인식 못 하는 메시지는 무시한다. 대소문자 무관.

## e-ink → 아이폰 (알림)

앱이 같은 토픽에 `Tags: focusink` 헤더로 게시한다(앱은 이 태그가 붙은 메시지를 명령으로 읽지 않는다). 아이폰에 ntfy 앱을 설치하고 토픽을 구독하면 푸시로 받는다.

- 세션 시작: `집중 시작 · <이름> · 90분 (10:30까지)`
- 세션 종료: `집중 끝 · <이름> · 87분 · 방해 2`
- 저녁 리뷰 완료: `오늘 딥워크 180분 · 블록 2 · 방해 4`

## 수신 시점

e-ink 앱은 (1) 앱이 화면에 올 때, (2) 집중 세션 중 60초마다 `GET /<토픽>/json?poll=1&since=<마지막 ID>` 로 가져온다.
